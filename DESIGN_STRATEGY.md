# EduVaani Design Strategy

## Product character
EduVaani should feel calm, credible, useful, and multilingual. It is an educational workspace, not a generic AI chat demonstration.

## Creative boundaries
- Use Taste only for public-facing brand and landing surfaces.
- Use Impeccable for application interface critique and polish.
- Use Emil Kowalski principles for purposeful interaction and motion.
- Keep operational screens dense only to the degree that readability improves.

## Approved visual foundation
- Deep educational green as the primary trust color.
- Warm neutral surfaces and high-contrast dark text.
- Serif display typography only for focused public and welcome moments.
- Sans-serif and Noto multilingual fonts for interface work.
- Restrained borders, limited elevation, and no decorative gradients.

## Quality gate
No screen scores below 8/10 in visual quality or accessibility. Functional, security, or accessibility defects block approval regardless of visual score.
