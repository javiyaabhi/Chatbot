# Competitor Analysis

## Comparison set
Duolingo, Khan Academy, Quizlet, Coursera, and modern AI tutoring interfaces provide useful patterns, but EduVaani should not copy a specific product.

## Patterns to learn
- Immediate, visible task entry.
- Clear progress and recent work.
- Friendly but purposeful teaching.
- Structured feedback after practice.

## Design risks to avoid
- Repetitive dashboard cards.
- Excessive decorative animation.
- Chat-first layouts with unclear learning goals.
- Generic product personas or invented learner data.
