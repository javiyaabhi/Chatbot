# Design Tokens

## Color
- Ink: #17221d
- Primary: #17382b
- Primary action: #25583f
- Surface: #f8faf7
- Neutral border: #dde5df
- Error surface: #fff1ef

## Typography
- Interface: Inter, system UI, Noto Sans Gujarati, Noto Sans Devanagari
- Editorial: Georgia for deliberate welcome and public moments

## Spacing
Use 4px as the base unit and 8, 12, 16, 24, 32, 48 spacing steps.
