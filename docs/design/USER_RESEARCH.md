# User Research

## Research status
No primary interviews or measured usage data exist in the workspace. This document records design hypotheses that must be validated before release.

## Hypotheses
- Students need a clear, low-pressure way to ask one question at a time.
- Language choice must be visible and persistent.
- Technical explanations benefit from short sections and practical examples.
- Long Gujarati and Hindi text requires more forgiving wrapping and line height than English.
- Conversation history is useful only when titles remain recognizable.
