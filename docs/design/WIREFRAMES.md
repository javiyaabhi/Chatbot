# Wireframes

The implemented vertical slice uses:
- Direct tutor entry with a private guest session.
- Desktop or tablet sidebar plus learning workspace.
- Mobile condensed navigation.
- Regular mode for open-topic questions and Specialized mode for a selected subject.
- A focused composer with persistent response-language control and teaching depth.
- A guided session dialog for selecting mode, subject, and response language.

Specialized subject scope is attached to each conversation and passed to the tutor. Guest conversations remain associated with the browser session. Detailed production wireframes should be reviewed before adding PDF, quiz, and analytics screens.
